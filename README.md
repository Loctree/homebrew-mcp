# homebrew-mcp

Homebrew tap for the Loctree MCP server.

This tap should track the latest `loctree-mcp` releases and provide the
user-facing install command:

```bash
brew install loctree/mcp/loctree-mcp
```

## Role

- formula only, no source code
- points at `Loctree/loctree-mcp` release assets
- stays thin so release updates stay fast
